# Huddle

A cozy community-chat interface built with HTML, CSS, and JavaScript. Open `index.html` directly or serve the repository with any static web server.

The app is a **local, single-browser demo**: messages, reactions, profile changes, and custom channels are stored in localStorage. It does not include accounts, real-time synchronization, file uploads, or voice chat. Invite links share the demo itself, not a live workspace. These features would require a backend and are not supplied by GitHub Pages.

To reset the demo, clear this site's local storage in your browser.
